# Web-Scrappers

some small web scrappers I wrote for some random projects.

- amazon: scrape product details from amazon.in
- besoccer: scrape data from besoccer.com
- etherscan: scrape data from etherscan.io
- foxnews: scrape news from foxnews.com
- webuycars: scrape car details from webuycars.com
- imdb: scrape movie and series details from imdb.com
